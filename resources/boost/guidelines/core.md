# DB Snapshot Sync

This project pulls its production database down to local with `php artisan snapshot:sync` (phattarachai/db-snapshot-sync-laravel), which logs in to the box over the developer's own ssh and runs `php artisan snapshot:export` there; there is no token or HTTP API. It replaces the local database, so run `php artisan migrate` afterwards for migrations newer than the snapshot. To load a snapshot already on the disk, spatie's `snapshot:load` is the normal default (e.g. `php artisan snapshot:load testing --env=testing --force` priming a test database from a small committed dump); switch to `php artisan snapshot:restore` once a dump is large or complex (a production or UAT dump, one too big to read whole into PHP memory, or a database that must not be left empty if the load fails), because it streams through psql in one transaction (or the mysql client) instead of dropping every table first and reading the whole file into memory. For options, ssh source setup and troubleshooting, use the `db-snapshot-sync` skill.
