# DB Snapshot Sync

This project pulls its production database down to local with `php artisan snapshot:sync` (phattarachai/db-snapshot-sync-laravel), which logs in to the box over the developer's own ssh and runs `php artisan snapshot:export` there; there is no token or HTTP API. It replaces the local database, so run `php artisan migrate` afterwards for migrations newer than the snapshot. To load a snapshot already on the disk, use `php artisan snapshot:restore`, never spatie's `snapshot:load` (which reads the whole dump into memory and drops every table first). For options, ssh source setup and troubleshooting, use the `db-snapshot-sync` skill.
